Проблема: 10-летний код

К нам обратился владелец интернет-магазина, который работал на одной и той же кодовой базе более 10 лет. За это время сайт обрастал новыми функциями без какой-либо архитектурной рефлексии. Основные проблемы:

  • Скорость загрузки страниц — 8 секунд (критично для SEO и удержания клиентов)
  • Сложность добавления нового функционала — любые доработки занимали недели
  • Высокий порог входа для новых разработчиков
  • Отсутствие документации
  • Критические уязвимости безопасности из-за устаревших библиотек
  • База данных с неоптимизированными запросами

Задача: провести полную реорганизацию кода без остановки работы магазина, сохранив весь существующий функционал.

Архитектурные проблемы

Главная архитектурная проблема заключалась в отсутствии четкого разделения ответственности. Весь код был смешан в одном файле:

"Один файл контроллера содержал более 5 000 строк кода, в которых были перемешаны запросы к БД, бизнес-логика, HTML-верстка и обработка форм."

Мы предложили архитектуру на основе MVC с четким разделением слоев:

  • Models — работа с данными, бизнес-логика
  • Views — только отображение данных
  • Controllers — обработка запросов, координация
  • Services — выделенная бизнес-логика
  • Repositories — слой работы с БД

Оптимизация и рефакторинг

Мы реализовали комплексную программу оптимизации:

Оптимизация запросов

Переписали 47 N+1 запросов на один JOIN-запрос. Внедрили индексы в БД.

Кэширование

Внедрили Redis для кэширования тяжелых запросов и рендеринга страниц.

Рефакторинг кода

Разбили монолитный контроллер на отдельные классы по принципу Single Responsibility.

Безопасность

Обновили все библиотеки, исправили уязвимости, внедрили строгую валидацию данных.

Frontend-оптимизация

Минифицировали CSS/JS, внедрили lazy-loading для изображений.

Автотесты

Написали > 200 юнит-тестов и интеграционных тестов для предотвращения регрессий.
