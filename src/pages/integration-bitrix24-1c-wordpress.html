Задача: сквозная интеграция

К нам обратилась сеть магазинов с задачей автоматизировать все бизнес-процессы:

  • WordPress — фронтенд, витрина магазинов
  • Битрикс24 — CRM для работы с клиентами и заказами
  • 1С:Предприятие — управление товарами, ценами, остатками
  • Платежные системы — ЮKassa, Сбербанк, Тинькофф

Ключевое требование: синхронизация данных должна происходить в реальном времени. При оформлении заказа на сайте данные должны мгновенно появляться во всех системах.

Архитектура интеграции

Мы разработали централизованную архитектуру на основе REST API и вебхуков:

WordPress → Битрикс24

При оформлении заказа вебхук отправляет данные в CRM. Клиент создается автоматически, заказ привязывается к клиенту.

1С → WordPress

Ежечасная синхронизация товаров, цен и остатков через JSON API. При изменении в 1С — обновление на сайте.

WordPress → Платежные системы

Интеграция через SDK платежных систем. Создание платежа, обработка успешных платежей, отправка чеков.

Битрикс24 → 1С

При закрытии сделки в CRM данные отправляются в 1С для формирования документов и заказа товаров.

Технический стек интеграции:

  • REST API
  • Webhooks
  • JSON
  • OAuth 2.0
  • Redis (кэширование)
  • RabbitMQ (очереди)
  • Docker

Интеграция с Битрикс24

Битрикс24 стал центральной точкой управления клиентскими данными. Что мы реализовали:

  • Автоматическое создание клиентов — при первом заказе создается карточка клиента в CRM
  • Синхронизация заказов — каждый заказ на сайте становится сделкой в Битрикс24
  • История взаимодействия — все коммуникации с клиентом логируются в CRM
  • Автоматические теги — клиенты автоматически получают теги по категориям товаров
  • Интеграция с почтой — автоматическая рассылка писем о статусе заказа

"Мы использовали стандартное REST API Битрикс24 с OAuth 2.0 авторизацией. Скорость создания сделки — менее 500 мс."

Интеграция с 1С

Самый сложный компонент — двусторонняя синхронизация с 1С. Мы реализовали:

  • Выгрузка товаров — из 1С в WordPress (названия, описания, цены, остатки)
  • Выгрузка заказов — из WordPress в 1С для формирования документов
  • Синхронизация статусов — изменение статуса заказа в 1С автоматически обновляет статус на сайте
  • Интеграция со складами — при изменении остатков в 1С сайт обновляется в реальном времени
  • Автоматическое списание товаров — при подтверждении заказа товары списываются со склада

Интеграция с WordPress

WordPress выполняет роль фронтенда. Мы реализовали:

  • Кастомный плагин интеграции — модуль, который связывает WordPress со всеми системами
  • Динамическое обновление каталога — автоматическое обновление товаров и цен
  • Оптимизация API-запросов — кэширование данных из 1С в Redis
  • Обработка вебхуков — при изменении в CRM или 1С сайт обновляется
  • Журнал событий — логирование всех интеграционных процессов

Особенность: мы использовали асинхронную обработку через очереди RabbitMQ, чтобы не тормозить работу сайта при синхронизации больших объемов данных.

Платежные системы

Для обработки платежей мы интегрировали три системы:

  • ЮKassa — основной платежный шлюз для банковских карт
  • Сбербанк — для корпоративных клиентов и безналичных расчетов
  • Тинькофф — для быстрых оплат через эквайринг

Что было реализовано:

  • Создание платежа в системе при оформлении заказа
  • Обработка статусов платежа (успешно, ошибка, ожидание)
  • Автоматическое обновление статуса заказа при успешной оплате
  • Отправка чеков клиентам через ФНС
  • Логирование всех транзакций для аудита
